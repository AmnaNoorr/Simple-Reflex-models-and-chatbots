## 📋 Overview

This repository contains the complete implementation for **Lab #3: AI Agents in Python**, covering the fundamental concepts of intelligent agents, the **PEAS (Performance, Environment, Actuators, Sensors)** framework, and **Simple Reflex Agents**.

The lab consists of two main Python programs:
1. **3-Square Vacuum World Agent (`task2.py`)**: A pure simple reflex agent operating across locations `A`, `B`, and `C`. The environment and starting conditions are passed at runtime by the user, and the agent uses a randomized action rule at position `B` to avoid deterministic ping-pong loops.
2. **Simple Reflex Chatbot (`task3.py`)**: A keyword-driven conversational agent extended with additional runtime rules, along with a written analysis comparing simple reflex architectures against model-based reflex agents.
